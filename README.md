# Магазин відеоігор — ГЗ 1.1

**Виконав:** курсант 231 навчальної групи, Медведський Артем Дмитрович.  
**Номер за списком:** 20.

Це **самостійний навчальний проєкт**, зроблений за вимогами з репозиторію викладача, а не копія AmazonUA. Предметна область — каталог вигаданих відеоігор (`VideoGame`).

- Java 21; Spring Boot 3.4.13; Maven.
- Backend API, без React або HTML-інтерфейсу (саме так вимагає ця ГЗ).
- Архітектура: `domain` → `repository` → `service` → `web`, інтерфейси на межах, конструкторна ін'єкція.
- In-memory сховище (без бази даних), 5 стартових ігор, короткі та детальні DTO.
- Детальні приклади запитів: [requests.md](requests.md).

## Як запустити в IntelliJ IDEA

1. Встановіть **JDK 21** (не Node.js) і відкрийте цю папку як **Maven project** (`pom.xml`).
2. Зачекайте, поки IntelliJ завантажить Maven-залежності; потрібен інтернет під час першого запуску.
3. Запустіть `src/main/java/com/ua/medvedskyi/games/GamesApplication.java` зеленою стрілкою біля `main`.
4. Перейдіть у браузері на <http://localhost:8080/api/games> — відкриється **JSON** зі списком ігор.
5. Тести запускаються у вікні Maven через **Lifecycle → test**, або в терміналі, якщо встановлено Maven:

```cmd
mvn test
mvn spring-boot:run
```

Якщо порт `8080` зайнятий SENTINEL чи іншим застосунком, у `cmd.exe` перед запуском задайте:

```cmd
set "SERVER_PORT=8081"
mvn spring-boot:run
```

Після цього змініть у запитах порт `8080` на `8081`.

## REST API

 | Метод | URL | Результат |
| --- | --- | --- |
| GET | `/api/games` | список карток, HTTP 200 |
| GET | `/api/games/{id}` | деталі гри, HTTP 200 або 404 |

## Які файли важливі

- `domain/VideoGame.java` — модель гри (назва, студія, платформа, жанр, рік, віковий рейтинг, ціна, обкладинка та опис).
- `repository/VideoGameRepository.java`, `InMemoryVideoGameRepository.java` — інтерфейс і сховище.
- `config/GameSeeder.java` — п'ять ігор, що створюються під час старту.
- `service/VideoGameService.java`, `VideoGameServiceImpl.java` — бізнес-логіка.
- `service/mapper/VideoGameMapper.java` — перетворення в `VideoGameCardDto` і `VideoGameDetailDto`.
- `web/VideoGameController.java` — 2 GET ендпоінти.

**Наступна ГЗ 1.2:** та сама предметна область доповнюється створенням, оновленням, видаленням і фільтрацією за жанром. Це окремий проєкт `amazonua-gz12` із комплекту.
